# ADMIN_GUIDE — دليل الإدارة / Admin Guide

## Arabic (العربية)

### تسجيل الدخول
1. افتح المتصفح → /login → أدخل البريد الإلكتروني وكلمة المرور.
2. إذا ظهر "في انتظار الموافقة"، انتظر موافقة المدير (يتم إرسال إLogoLand automatically).

### إضافة طلاب
- المستخدمون → أضف طالب، أو استخدم "استيراد CSV" (email,password,role).
- الطلاب → تحديد students → "موافقة" أو "رفض" أو "تسجيل في مادة".

### إضافة م teaches
- دعوات → إنشاء دعوة (الاسم، "Dr" أو "Eng"، البرنامج).
- نسخ الرابط، إرسال إلى email المدرse (هذه يعمل 30 يوم).
- المدرس يضبط word(MSG) then it's done automatically on first click.

### الجدول (Timetable)
- جدول الحصص → اختر program/level/group/semester → edit cells → auto-create courses/rooms/instructors inline.
- بعد edit, generated sessions can be regenerated (future only).
- كاتب "طباعة" to print with college header.

### الحصص (Sessions)
- Start/stop manually or from schedule; extend; cancel.
- Mark attendance manually after close with reason.
- Substitute a professor for one session.

### المراجعة (Review)
- Flagged attempts: فغرRRE under "Flagged Attempts".
- Disputes: approve/reject.
- excuses: approve/reject.

### Trash
-_restore from trash by admin.

## English

### Login
Open browser → /login → enter email/password. If status shows "pending", wait for admin approval.

### Add students
Users → Add user, or "Import CSV" (email,password,role). Students → select → bulk Approve/Reject or Enroll to course.

### Add instructors
Invites → Create invite (name, title Dr/Eng, program). Copy link, send to instructor's email. Valid 30 days. Account is auto-created on first claim.

### Timetable
Timetable → pick program/level/group/semester → edit cells → create/edit courses/rooms/instructors inline. After editing, regenerate sessions for future only. "Print" exports with college header.

### Sessions
Start/stop manually or from schedule; extend; cancel. Mark attendance manually after close with reason. Substitute a professor for an occurrence.

### Review
Flagged attempts → see anti-fraud signals. Disputes → approve/reject. Excuses → approve/reject.

### Trash
Restore or permanently purge from /admin/trash.
